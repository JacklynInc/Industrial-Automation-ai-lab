# Industrial Automation AI Lab

A progressive engineering portfolio exploring **industrial automation, Industrial IoT, data monitoring, and AI for smart manufacturing**.

The projects follow one continuous technical journey:

> **AUTOMATE → MONITOR → PREDICT**

---

## 🚀 Project Roadmap

### 01 — AUTOMATE
**Automated Production Cell**

Built an automated production-cell simulation combining industrial control logic, Python, PLC/TwinCAT concepts, quality inspection, and production data logging.

**Focus:** Industrial Automation · PLC · TwinCAT · Python · Production Systems

[View Project 01](./Project-01-automated-production-cell)

⬇️

### 02 — MONITOR
**Industrial Monitoring Platform**

Extended the industrial environment with machine-condition monitoring. Sensor data is transmitted through MQTT, processed with Python, stored in SQLite and InfluxDB, visualized with Grafana, and connected to automated alerts through n8n and Telegram.

**Focus:** IIoT · MQTT · Python · InfluxDB · Grafana · Industrial Monitoring

[View Project 02](./Project-02-industrial-monitoring-platform)

⬇️

### 03 — PREDICT
**AI Predictive Maintenance**

The next stage extends the monitoring platform with machine-learning techniques for anomaly detection and predictive maintenance.

**Focus:** Machine Learning · Anomaly Detection · Predictive Maintenance · Industrial AI

## 🎯 Portfolio Objective

The goal of this lab is to demonstrate a practical progression from **industrial automation and machine control**, through **industrial data acquisition and monitoring**, toward **AI-assisted predictive maintenance**.

The projects combine engineering principles with modern software, IoT, automation, and AI technologies to explore solutions for **smart manufacturing and Industry 4.0**.
